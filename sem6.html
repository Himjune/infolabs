Что сейчас хранится в массиве

Карточка — одна целая запись. Индекс зависит от порядка в массиве. При фильтрации скрытые строки остаются в памяти.

    Порядок работы: 2 минуты — алгоритм, 9 минут — реализация, 4 минуты — проверка и объяснение соседу. Для каждого варианта сначала заново загрузите контрольные данные, чтобы предыдущая сортировка или правка балла не меняла ожидаемый ответ.

    Вариант 1 · Группа

    Вывести студентов выбранной группы. Группу ввести в TextBox; сравнивать строки полностью с учётом регистра.

    Trim у запроса; String::Equals; цикл только до n; исходный массив не менять.

    Контрольный ответ

    ИУ5-11 → Иванов, Сидоров, Орлова: 3 записи. ИУ5-99 → 0. Пустой запрос → понятное сообщение.

    Вариант 2 · Средний балл

    Найти средний балл по всем студентам. Вывести результат с одним знаком после запятой.

    До деления проверить n > 0. Сумма должна делиться вещественно: double(sum) / n.

    Контрольный ответ

    Сумма 412, средний 82,4. Для пустого массива — сообщение без деления на ноль. Для одного студента — его балл.

    Вариант 3 · Все лучшие

    Вывести всех студентов с максимальным баллом, а не только первого.

    Два прохода: найти максимум, затем отобрать равные ему баллы.

    Контрольный ответ

    Петрова и Ким: по 94. Если все баллы одинаковы — показать всех. Если n=0 — сообщение.

    Вариант 4 · Удаление

    Удалить запись по индексу. Сдвинуть следующие записи на одну позицию влево и уменьшить n.

    Проверка 0 ≤ index < n; присваивать целую запись; размер массива остаётся 500.

    Контрольный ответ

    Удалить индекс 1 → Иванов, Сидоров, Ким, Орлова; n=4. Удалить единственную запись → n=0. Индекс n недопустим.

    Вариант 5 · Фамилии по алфавиту

    Отсортировать записи по фамилии, сохраняя группы и баллы.

    В пузырьковой сортировке сравнить String::Compare(name1, name2, StringComparison::Ordinal) > 0. Равные строки не обменивать.

    Контрольный ответ

    Иванов, Ким, Орлова, Петрова, Сидоров. В примере все фамилии с одинаковым регистром начала. Ordinal задаёт порядок кодов UTF-16, а не полноценный словарный порядок русского языка: отдельно обсудите «Ё» и регистр.

    Вариант 6 · Обратно в строки

    Преобразовать заполненную часть массива записей в массив строк «фамилия;группа;балл» и вывести в текстовое поле.

    gcnew array<String^>(n); String::Format; присвоить Lines один раз после цикла.

    Контрольный ответ

    Получаются исходные 5 строк в текущем порядке записей. Для пустого массива — пустой результат. Загрузите полученные строки обратно и сравните все поля.
