Условие

Ведомость содержит от 1 до 30 студентов. Для каждого известны ФИО, группа, пропуски в часах и средний балл. Программа принимает данные из таблицы, хранит их в массиве записей, сортирует по баллу, отбирает студентов одной группы и выводит статистику.

    Номер варианта = (номер в журнале mod 6) + 1. Сначала запишите на листе шаги реализации по порядку, как на занятии, затем напишите код. Имена новых переменных и надписи придумайте сами.

    Вариант 1

    Отбор студентов, у которых пропусков больше заданного числа (новый NumericUpDown).

    Шаблон — шаг 15 «Отбор по группе», меняется только условие.

    Вариант 2

    Сортировка записей по ФИО в алфавитном порядке.

    String::Compare(a, b) > 0 — записи надо поменять местами.

    Вариант 3

    Средний балл отдельно по каждой группе, результат — в таблицу из двух столбцов.

    Сначала соберите массив различных групп, затем сумму и количество для каждой.

    Вариант 4

    Удалить из массива записи с баллом ниже 3,0 и вывести оставшиеся.

    Сдвигайте подходящие записи к началу, считая их; затем вызовите функцию вывода массива.

    Вариант 5

    Поиск по части ФИО: подсветить найденные строки таблицы ввода цветом.

    Rows[i]->DefaultCellStyle->BackColor = Color::LightYellow; и Contains(...)

    Вариант 6

    Добавить в запись поле «Год рождения» и столбец в обе таблицы, найти самого младшего.

    Измените тип записи, функцию столбцов, чтение и вывод массива.

    Критерии: программа компилируется; ошибка ввода подсвечивается, а не роняет программу; результат виден в таблице результата или в строке состояния.
